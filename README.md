An entry for the [make.fun](https://make.fun) competition
"The Postmortem That Made Us Laugh"
([competition page](https://make.fun/competitions/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3)).

## The entry

`main.py` (Python 3.13, stdlib only, no network) writes one short account —
one or two sentences, at most 400 characters — of the silliest time an AI
coding agent wrecked the code it was given, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
